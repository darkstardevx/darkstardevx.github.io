# Homepage asset pack

- `darkstar-mark.svg` — source vector mark for the header and favicon.
- `darkstar-mark-*.png` / `darkstar-mark.ico` — ready-to-use icon sizes.
- `atlas-hero.png` / `atlas-hero.webp` — wide Signal Atlas hero artwork.
- `atlas-card.webp` — compact texture for the Field Guide panel and statement modal.
- `social-card.jpg` — 1200×630 Open Graph preview image.

The raster artwork was generated as a project visual, then cropped and optimized locally for the page’s different surfaces. The typography and layout remain HTML/CSS so they stay accessible and responsive.
